# 願景凍結 — 全域 AI 餐飲智慧營運作業系統

> 此文件為**指揮官原始願景的凍結版**。後續所有 PRD、Spec、Schema、程式碼皆以此為單一事實來源（Single Source of Truth, SSOT）。
> 願景如需修訂，請以 PR 形式更新本檔，並在 commit message 註記變更理由。

---

## 一、戰略定位

打造**台灣餐飲業空白市場的終極解決方案**：一套覆蓋路邊攤、小店、單店、大店、百貨櫃位、連鎖直營、加盟總部的全場景 AI 自動運行作業系統。

> **核心宣言：一套系統，解決台灣餐飲 99% 營運痛點。**
> 不是「再多一套 POS / ERP / CRM」，而是把所有數據打通、由 AI 蜂群 24 小時自主運行的「餐飲神經網路」。

## 二、市場差異點

台灣現有餐飲軟體的致命缺口：

| 缺口 | 現況 | 本系統解法 |
|---|---|---|
| 數據孤島 | ERP、CRM、人事、行銷、地圖各自獨立 | 統一向量化中台，事件全打通 |
| 假獲利 | 只算表面營收 | 真實毛利 / 真實淨利（含招待、折扣、損耗、員工餐、試吃、報廢） |
| 損耗黑洞 | 永遠抓不住 | BOM 配方扣料 + 異常耗料 AI 預警 |
| 人力混亂 | 排班內耗、無法量化 | 打卡 / 排班 / 請假 / 加班 全自動 |
| 行銷靠感覺 | 無 ROI 量化 | 活動成效 AI 演算（帶客 / 轉單 / 毛利影響） |
| 加盟無管控 | 標準化困難 | 多店總部、權限、任務、稽核系統 |
| 地圖脫節 | 業界完全沒人整合 | Google 地圖定位 + 區域消費力 + 競品數據 |

## 三、適用對象（全場景覆蓋）

1. 路邊攤、小吃店、單點小店
2. 中大型餐廳、火鍋店、異業餐飲
3. 百貨公司專櫃、商場門店
4. 連鎖品牌直營店
5. 加盟總部 + 加盟店體系

## 四、七大核心模組（全串聯，無數據斷層）

### 模組一：AI 全能 ERP（進銷存｜成本｜損耗｜庫存｜物料）
- 食材進貨 / 耗料 / 庫存自動對帳
- 每日精算損耗率
- 報廢 / 試吃 / 員工餐 / 過期自動扣帳
- 變動成本即時更新
- BOM 標準配方，異常耗料 AI 主動警示

### 模組二：AI CRM 會員精準經營
- 顧客消費畫像 AI 標籤
- 回購率 / 流失率 / 高價客 / 潛力客自動分級
- 自動發送優惠、生日禮、喚回行銷
- 整合消費 / 招待 / 折扣紀錄

### 模組三：AI 人事管理（考勤｜調度｜異常監控）
- 打卡 / 遲到 / 早退 / 請假 / 換班
- 當日人力缺口 AI 分析
- 排班優化、尖峰調度建議
- 薪資基礎運算 / 工時 / 加班紀錄

### 模組四：AI 全域行銷自動化
- 活動一鍵上架
- 活動成效 AI 演算（ROI 量化）
- 曝光 → 引流 → 轉單 → 回購閉環
- 自動判斷哪種行銷最賺錢、哪種虧損

### 模組五：Google 地圖 / 定位 / 門市全域系統（業界獨有）
- Google Maps 官方定位、營業資訊綁定
- 地圖資訊錯誤 AI 偵測
- 區域流量 / 競品 / 消費力數據導入
- 新店選址數據參考
- 連鎖多店定位管理

### 模組六：AI 全方位運算公式｜自動報表體系（核心靈魂）
**算「老闆真正口袋剩下的錢」，不是表面營收。**
- 每日真實營收 / 淨營收
- 每日食材成本 / 變動成本
- 固定成本攤提（租金、水電、折舊）
- 真實毛利 / 真實淨利
- 損耗、招待、折扣、折讓獨立核算
- 日 / 週 / 月 成長率 AI 趨勢
- 獲利模型 / 虧損模型自動診斷

### 模組七：AI 營運管理｜群組任務｜總部監控（連鎖專用）
- 階層權限：老闆 / 店長 / 主廚 / 幹部 / 總部
- 任務發布、追蹤、KPI 監控
- 多店總部總覽
- 加盟店數據上鏈、總部稽核
- SOP 系統化、異常 AI 預警

## 五、雙層架構（戰略級分層）

### Layer 1 — DevSwarm（研發端 AI 軟體製造工廠）
不僱用人類工程師，而是建立自我迭代的 AI 蜂群：
- **PM Agent** — 戰略需求 → PRD + API 規格 + Schema
- **架構與安全 Agent** — 預先注入資安框架（GDPR / 個資法）
- **編碼蜂群（Frontend + Backend）+ QA Agent** — 自我修復循環，直到壓測通過
- **DevOps Agent** — 自動容器化、K8s 部署、Prometheus 監控

> **本 repo 的第一交付物即為 DevSwarm 骨架（LangGraph）。**

### Layer 2 — RestSwarm（餐飲端神經網路）
DevSwarm 產出的應用層，由三大閉環構成：

1. **營收 / 自媒體永動閉環**
   數據分析 → 行銷策略 → 創意生成（影音 / 圖）→ 社群矩陣自動發佈 → LINE CRM 精準推播

2. **供應鏈 / 財務無人閉環**
   點餐扣料 → 天氣 / 歷史預測 → 自動詢價 → 採購單一鍵審批 → 電子錢包對帳付款

3. **人資 / 現場調度閉環**
   出餐超時偵測 → 排班比對 → 個人化 SOP 微課程推送 → 自動配對資深員工

## 六、商業模式

### 量化交付（賣的不是功能，是 ROI 儀表板）
- 「本月 AI 為您挽回流失客 230 人，創造營收 15 萬」
- 「精準採購減少食材浪費 18%，省下 4 萬」
- 「AI 排班降低管理內耗，店長省下 32 小時」

### 一鍵品牌克隆（1-Click Brand Cloning）
- Step 1：上傳菜單照、店面照、品牌偏好
- Step 2：AI 蜂群 10 分鐘內解析菜單、建立 POS / ERP / 知識庫 / 社群初稿
- Step 3：硬體連網即啟動

### 商業價值四軸
1. **自用** — 自家品牌營運零漏洞、獲利最大化
2. **外售** — 台灣餐飲 SaaS 獨家產品
3. **加盟護城河** — 加盟店強制導入
4. **數據資產** — 累積台灣最完整的餐飲營運 AI 數據庫

## 九、為什麼不等別人做？

台灣餐飲業共同致命問題：
- 數據分散在五六套軟體
- 不知道真實每天賺多少、虧多少
- 損耗永遠抓不住
- 人力管理混亂
- 行銷不知道有沒有效
- 連鎖加盟沒有標準化管控
- 地圖曝光、門市定位無法數據化

**目前沒有人做出來。指揮官即將開店，必須先把這套東西完善。**
