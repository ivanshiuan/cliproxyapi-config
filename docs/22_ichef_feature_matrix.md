## 5. 我們有、iCHEF 沒有（或做不到）的

| 我們的獨有 | 說明 |
|---|---|
| 全開放 API + Web 架構 | iCHEF 鎖 iPad；我們任何裝置瀏覽器都能跑（平板/手機/電腦） |
| append-only 稽核帳本 | 退菜/折扣/庫存/點數不可竄改，授權者+方式全記錄 |
| WebSocket 即時事件流（斷線游標補洞） | 四端（POS/顧客/KDS/後台）同一條流，秒級同步 |
| 行銷成長飛輪 | 開幕輪盤、裂變邀請碼、UGC 換獎、儲值加贈、連續回訪加碼 |
| 主管覆核精細度 | audit 記錄「誰授權、self/override」，iCHEF 只有權限鎖 |
| 自建=零月費零抽成 | iCHEF $1,950/月起、掃碼點餐另計、金流 2.2% 起 |
