# 26 — 介面拆解：iCHEF × 世界級 POS（P10 重製藍圖）

> 2026-07-16。兩路研究彙整：iCHEF 介面與操作（20+ 來源，官方知識庫為主）＋
> Square/Toast/Lightspeed/Eats365 世界級規範（20+ 來源）。docs/25 計畫的第 1 步產出。
> 註：像素級比例/色票各家皆不公佈；下方「規格」欄是我們自己的定案值。

## 1. iCHEF 的 10 條介面原則（附證歸納）

1. **狀態即顏色，顏色即行動**：訂單四色 紅=待送單 / 黃=已送廚 / 綠=待結帳 / 藍=已結帳可關桌
2. **一顆按鈕三種速度**：結帳鈕 點一下=完整流程、點兩下=跳過折扣、右滑=預設付款秒結
3. **不可逆動作用「滑動」確認**（結帳）、可逆動作用點擊——防誤觸入帳
4. **拖曳取代表單**：按住訂單卡拖到桌=換桌、拖到另一單=併單
5. **Just Fit**：沒用的功能整塊不出現（不是灰化）
6. **沿服務員動線排頁面**：登入→桌位→點餐→折扣→結帳→工具箱 = 帶位→點餐→送廚→收款→交接
7. **左資訊右操作固定分欄**：左=單號/人數/備註/已點清單，右=菜單鍵盤；結帳與工具箱固定右下（拇指區）
8. **動作完成自動歸位**：送單後自動跳回桌位頁（下一件事是服務下一桌）
9. **提醒不擋路**：訂位/遲到標示只提示不封鎖；防呆放在錢的關卡不放在服務的關卡
10. **報表用比較說話**：柱狀 黑=持平/藍=變好/紅=變差，自動對基期

其他關鍵細節：點餐頁左欄含可編輯人數/備註；菜單第一分頁=全品項清單、其餘=後台排版格狀頁；
底部工具列可現場調字級字色/切品項售完；同品項同註記自動併行；桌卡 QR 說明文字依先結/後結自動切換；
候位登記顯示姓名/人數/電話/需求/已等時間；帶位開單一鍵（訂位→開桌→帶會員資料）；
總部改菜單需按「菜單同步」才生效。

## 2. 世界級 12 條規範（Square/Toast/Lightspeed/Eats365）

1. 點餐雙欄：帳單欄常駐一側（30–35% 起測）
2. 菜單導覽最多三層，每層一次觸擊
3. 磁磚 2–3 種尺寸＋自訂色＋分頁
4. 觸控目標 ≥48px、間距 ≥8px、必有 pressed 高亮
5. 高頻動作鎖螢幕底部常駐；低頻危險收 overflow
6. 桌況色：空=中性、入座未點=黃、用餐=主色、已印帳單=橘、待清=強暖；他人桌用標籤
7. 深淺主題都做、裝置層級開關
8. 破壞性動作永遠同一個紅、永不放熱區旁
9. 字級三層：應付總額最大 > 品名/桌號 > 輔助；正文 ≥16px；品名字級可調
10. 現金動態快捷鈕：依應收產生 $100/$500/$1000 面額鈕，可連按累加
11. Fast 現金一鍵關單（Toast Fast $$：不彈 $0 找零框、關單回點餐頁）
12. 退菜/作廢＝主管 PIN＋強制原因＋確認；「送單」是不可逆界線，未送單可自由刪

## 3. 我們的設計系統定案（P10 tokens）

**色彩（深色為主題基底，另出淺色）**
- 底 `#101418` / 面板 `#1A2028` / 面板2 `#232B35` / 線 `#2E3742`
- 文字 `#EEF2F7` / 次要 `#93A0AE`
- 品牌主色（用餐中/主按鈕）`#E8833A` 橙
- 狀態：待送單紅 `#E05252`、已送廚黃 `#EFB53E`、待結帳綠 `#35C26E`、已結帳藍 `#4C8DFF`、待清橘 `#E8833A`
- 破壞性動作紅 `#E05252`（全系統唯一紅，永不與主按鈕相鄰）

**字級（平板 1024+）**：應付金額 34–40 / 頁題 22 / 品名與桌號 17–18 / 正文 16 / 輔助 13.5；金額一律 tabular-nums

**觸控**：最小 48px、間距 ≥8px、主按鈕高 56px、pressed 態必亮

**版面**：點餐頁 左欄帳單 34% 常駐＋右欄菜單磁磚（分類頁籤在上）；「送單」「結帳」鎖底部；
結帳頁 數字鍵盤＋$100/$500/$1000 快捷鈕＋自動找零；桌位卡帶狀態色條＋人數/時間 icon

## 4. 比 iCHEF 更好的五個決定

1. **四色狀態直接上桌位卡**（iCHEF 在訂單卡）——桌位頁一眼看全店節奏
2. **快捷現金鈕動態化**（Square 依歷史、Toast 依應收）——台幣 $100/$500/$1000＋「整數收訖」
3. **結帳三速手勢照抄再加防呆**：右滑秒結保留，但滑動軌跡需 >60% 寬才觸發
4. **Web 跨裝置**：同一套 UI 自適應 iPad/Android 平板/手機（iCHEF 鎖 iPad）
5. **報表比較色（黑/藍/紅）與四色狀態共用同一套語意色票**——全系統一種顏色語言
