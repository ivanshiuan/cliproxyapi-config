# Goodgle 冷啟動策略：公益引流優先 × 雙通路混合地推

> 作戰手冊 v1.0｜給看結果不看程式碼的指揮官
> 主題：Goodgle 寵物生態系市場冷啟動 — 切入點定奪與第一線地推話術
> 結論一句話：**先用「公益狗糧兌換」零摩擦引流，咖啡廳深耕打磨信任、公園盲推規模放量，30 天後再橋接付費健保。**

---

## 1. TL;DR 一頁決斷

- **切入點**：**絕對優先「公益狗糧兌換」**，健保訂閱**暫緩**，留到信任建立後再橋接。
- **為什麼**：健保要碰用戶的錢包與寵物的命，新 App 防備心最重；公益是「零成本的善意」，摩擦力幾乎為零，能用最低獲客成本（CAC）洗出第一批高黏著用戶。
- **怎麼打**：**雙通路混合** — 通路 A「寵物友善咖啡廳」做點對點深耕（**信任模板**，先打磨話術與素材）；通路 B「大型寵物公園」做高密度盲推（**放量引擎**，規模化複製）。
- **節奏**：先 A 後 A+B 疊加；A 驗證出的最佳話術移植到 B，B 蒐集到的高頻反對意見回灌 A 持續優化。
- **付費伏筆**：註冊當下輕輕一推「之後會有專屬寵物健保，紀錄越多保費越便宜」，種下種子但**不在第一線推銷**。

---

## 2. 策略決斷：為何「公益狗糧兌換」絕對優先

若初期追求「最穩健、不出錯、能極速擴張」的路徑，公益狗糧兌換是唯一正解。三個核心理由：

### 2.1 避開高額「信任稅」
「健保訂閱」牽涉用戶的**錢包**與寵物的**生命安全**，對一個全新 App 而言，用戶防備心極重，推廣阻力與教育成本過高。第一次接觸就談付費，等於在信任帳戶餘額為零時就要求大額提款 —— 轉換必然慘澹，還會燒掉品牌第一印象。

### 2.2 零摩擦力的增長飛輪
公益狗糧切中的是「零成本的善意」。用戶不必掏錢，只需改變一點點行為習慣（用 Goodgle 紀錄散步、心情、便便），就能換到極大的**道德滿足感**與**社交貨幣**（「我每天遛狗就能養活一隻流浪狗」是天然會被分享的故事）。這能以極低的 CAC 快速洗出第一批**精準、高黏著的活躍用戶**。

```
零成本善意 → 行為紀錄（骨頭幣）→ 道德滿足 + 社交分享 → 更多新用戶
        ↑__________________ 低 CAC 飛輪 __________________↓
```

### 2.3 為付費自然鋪路
當用戶透過公益打卡在平台沉澱了 **30 天的行為數據**、對品牌產生信任後，再透過站內信／App 內推送「首月健保體驗優惠」，轉換率將呈現指數級躍升。順序是關鍵：**先給予價值與信任，再請求付費**，而非反過來。

> 一句話：公益是入口，數據是橋，健保是變現終點。順序錯了，飛輪轉不起來。

## 3. 雙通路混合打法設計

兩條通路不是二選一，而是**分工協作**：A 負責「把話術與素材打磨到最佳」，B 負責「把驗證過的東西規模化複製」。

### 通路 A｜寵物友善咖啡廳深耕（信任模板）

**定位**：低風險、高信任的實驗室。先在這裡把話術、素材、掃碼動線跑順、跑出數據，再外推。

| 項目 | 設計 |
|---|---|
| 場景 | 寵物友善咖啡廳、寵物餐廳（客人停留久、心情放鬆、防備低） |
| 合作形式 | 點對點深度合作：店主背書 + 桌卡／立牌靜態觸發 + 結帳時口頭轉介 |
| 核心優勢 | **店主信任轉嫁** —— 熟客信任店家，店家推薦 = 高轉換背書 |
| 角色分工 | ① 商務 BD：談店家合作、給店家分潤或公益榮譽牆<br>② 駐點專員（1 人）：定點不掃街，等客人自然詢問<br>③ 內容：設計高質感桌卡 + 即時捐糧視覺 |
| 週節奏 | 每週談下 3–5 家新店、回訪既有店補素材、收集當週反對意見清單 |
| 資源配置 | 輕量人力（1–2 人）、重素材投資（質感物料一次做好可複用） |
| 成功訊號 | 單店每週穩定產出 N 個註冊；話術反對意見收斂到可標準化 |

### 通路 B｜大型寵物公園盲推（放量引擎）

**定位**：把 A 驗證過的最佳話術，用人海與密度規模化。

| 項目 | 設計 |
|---|---|
| 場景 | 週末的大型寵物公園、寵物市集（毛孩密度最高、主人心情最好） |
| 合作形式 | 高密度掃街盲推 + 現場註冊禮 + 即時捐糧視覺衝擊 |
| 核心優勢 | **觸及量大、情緒場景對** —— 主人正陪狗玩，最容易被「為狗做公益」打動 |
| 角色分工 | ① 地推班長：控場、補位、即時調整話術<br>② 地推專員（3–6 人）：執行四步話術、掃碼<br>③ 機動：背即時捐糧看板 / 發註冊禮 |
| 班表 | 週末 2 天為主、鎖定早晨與傍晚遛狗尖峰（避開正午高溫） |
| 轉換漏斗 | 接觸 → 停下聽 → 掃碼下載 → 完成首次紀錄 → 領禮 |
| 資源配置 | 重人力（一場 4–8 人）、現場禮品 + 即時捐糧道具 |
| 成功訊號 | 單場接觸→註冊轉換率達標；單註冊 CAC 低於目標線 |

### 兩者協同關係（混合打法的精髓）

```
通路 A（咖啡廳）──── 驗證最佳話術／素材 ────▶ 通路 B（公園）規模化複製
       ▲                                              │
       └──────── 高頻反對意見回灌 A 優化 ◀────────────┘
```

- **A → B**：A 在低壓環境把話術、桌卡視覺、掃碼動線打磨到最佳，成熟後直接移植給 B 的地推團隊，B 不必從零試錯。
- **B → A**：B 因接觸量大，最快蒐集到各種反對意見與拒絕理由，整理成清單回灌 A，反覆迭代標準回應。
- **資源節奏**：第 1–2 週只跑 A（打磨）；第 3 週起 A 持續 + B 疊加放量。

## 4. 地推話術腳本（可直接照唸）

> 核心邏輯：**降維溝通**。不談偉大願景，只談眼前最簡單的動作與最直觀的愛心。

### 4.1 通路 B｜公園版四步話術

**目標場景**：週末寵物公園、寵物市集。

**第 1 步 — 破冰與鉤子（3 秒吸引注意）**
> 「哈囉！你們家毛孩好漂亮，是（品種）對不對？我們現在有一個『你遛狗、我們幫你捐狗糧』的活動，**完全免費**，要不要替狗狗做個公益？」
>
> *動作：遞上印有可愛流浪狗與 QR Code 的質感傳單，或直接展示 App 內已累積的「狗糧山」照片。*

**第 2 步 — 核心機制說明（10 秒建立信任）**
> 「我們是 Goodgle，正在推動流浪動物零安樂死。你只要下載 App，每次帶牠出來散步時按個開始、或拍張照紀錄一下心情，系統就會自動幫你累積『骨頭幣』。這些幣可以直接換成實體的高級狗糧，我們會直接送到指定的收容所。**你不用花半毛錢，你們家寶貝每天的散步，就能養活一隻流浪狗！**」

**第 3 步 — 促銷行動與臨門一腳（消除抗拒）**
> 「現在現場下載註冊，我們馬上先送你家寶貝一份（高顏值零食／實用便便袋），而且系統會**立刻先捐出 100g 狗糧**到收容所！我幫你掃這個條碼，不用一分鐘就好。」

**第 4 步 — 埋下付費伏筆（完成註冊後輕輕一推）**
> 「註冊好囉！對了，裡面還可以順便紀錄狗狗的便便狀況和活動量，AI 會幫你分析牠健不健康。你先用用看、累積公益幣，**之後我們還會推出專屬的寵物健保，用這個 App 紀錄越多、以後保費越便宜喔！**」

### 4.2 通路 A｜咖啡廳版（店內情境改寫）

**差異**：不主動掃街，靠店主轉介 + 靜態觸發 + 客人自然詢問。語氣更輕、更聊天。

**店主轉介切入（由店家說或駐點專員接話）**
> 「我們這邊有跟 Goodgle 合作一個遛狗捐狗糧的公益活動，很多客人都加入了。你愛狗的話超適合 —— 完全免費，掃個碼紀錄一下散步，就能幫收容所的浪浪換狗糧。」

**桌卡靜態觸發（印在桌卡上的文案）**
> 「☕ 喝杯咖啡的時間，也能幫浪浪一餐。
> 掃碼加入 Goodgle，你家毛孩每天的散步＝收容所的一碗飯。免費、一分鐘、即刻捐糧。」

**客人詢問後的回應（同公園版第 2–4 步，語氣放慢）**
> 機制說明 → 現場註冊禮（可改為「跟店家換一份毛孩點心」）→ 付費伏筆，照唸公園版即可。

### 4.3 反對意見處理（標準回應）

| 客人疑慮 | 標準回應 |
|---|---|
| 「免費的，是不是有詐？」 | 「完全免費、不收任何費用。我們靠的是讓更多人一起紀錄，品牌方贊助狗糧。你現在掃碼，系統馬上先捐 100g 給收容所，你親眼看得到。」 |
| 「要不要綁信用卡／付錢？」 | 「不用！註冊只要手機就好，**全程不需要任何付款資訊**。健保那些是之後你自己想用才考慮，現在純公益。」 |
| 「我的資料安全嗎？」 | 「我們只記散步和毛孩健康紀錄，不會亂用你的個資。隱私設定你隨時可以自己關。」 |
| 「我沒時間用 App。」 | 「超快的，散步按一下『開始』就好，連拍照都可以省。光是你今天這趟，就已經幫浪浪捐一餐了。」 |
| 「我家是貓 / 沒養狗。」 | 「沒問題！紀錄你對浪浪的關心一樣能累積公益，之後也會有貓咪的健康功能，先加入卡位最划算。」 |

## 5. 漏斗與北極星指標

**北極星**：D30 仍持續紀錄的活躍用戶數（代表「公益→留存」飛輪真的轉起來了）。

```
觸及 ──▶ 停下聽 ──▶ 掃碼下載 ──▶ 完成首次紀錄 ──▶ D7 留存 ──▶ D30 留存 ──▶ 公益轉付費
```

| 漏斗階段 | 通路 A（咖啡廳）假設 | 通路 B（公園）假設 | 量測檢核點 |
|---|---|---|---|
| 接觸 → 掃碼下載 | 較高（店主背書） | 較低（陌生盲推） | 現場計數 vs App 新增 |
| 下載 → 完成首次紀錄 | 高 | 中 | App 內事件埋點 |
| 首次紀錄 → D7 留存 | 觀察基準 | 觀察基準 | 留存報表 |
| D7 → D30 留存 | 觀察基準 | 觀察基準 | 留存報表 |
| D30 → 公益轉付費 | — | — | 第 30 天站內推送轉換率 |

> 指標紀律：**先看 CAC 與 D30 留存，再看註冊絕對數**。便宜但留不住的用戶是假增長。
> 兩通路各自算 CAC（A＝物料+少量人力／註冊數；B＝人力+禮品+捐糧／註冊數），用來決定後續資源往哪邊加碼。

## 6. 風險與容錯

| 風險 | 說明 | 降風險動作 |
|---|---|---|
| 公益疲乏 | 「捐狗糧」新鮮感退燒、轉換下滑 | 階段性換主題（指定收容所、毛孩限定徽章、社群排行榜）保持新鮮 |
| 捐糧成本失控 | 註冊量大時實體捐糧支出爆量 | 設每日／每場捐糧上限與預算閘門；用「累積里程碑式捐贈」取代逐人即捐 |
| 店家關係維護 | 咖啡廳合作熱度衰退、桌卡被撤 | 給店家公益榮譽牆／分潤／定期回訪補素材，把店家變成共同主角 |
| 法遵：個資 | 蒐集散步與寵物健康紀錄涉個資 | 明確隱私政策、最小化蒐集、提供用戶自助關閉與刪除 |
| 法遵：公益捐贈承諾 | 「即刻捐 100g」「換實體狗糧」是對外承諾 | 留存實際捐贈憑證並公開徵信，承諾與履約一致，避免不實宣傳爭議 |
| 第一線品質不一 | 地推話術因人而異、體驗落差 | 用通路 A 把話術標準化後再放量到 B；班長現場即時校正 |

## 7. 30 天執行排程

| 週次 | 重點 | 通路 A（咖啡廳） | 通路 B（公園） | 里程碑 |
|---|---|---|---|---|
| 第 1 週 | 打地基 | 談下首批 3–5 家店、上線桌卡、跑首批註冊 | 籌備（物料、禮品、捐糧道具、班表） | 話術 v1 上線、掃碼動線跑通 |
| 第 2 週 | 打磨 | 收反對意見、迭代話術 v2、補素材 | 小規模試跑 1 場驗證流程 | 話術收斂、CAC 初值出爐 |
| 第 3 週 | 疊加放量 | 持續深耕 + 擴店 | 正式週末高密度盲推 | A+B 並行、單場轉換達標 |
| 第 4 週 | 規模化 + 橋接 | 擴到第二批店家 | 加場、複製最佳班組 | 首批 D30 用戶站內推「首月健保體驗」測轉換 |

> 月底覆盤三個數字：**總註冊數、兩通路各自 CAC、D7 留存**。據此決定第二個月資源配比，以及健保橋接是否正式啟動。
