# 店長操作手冊 — 開幕引流輪盤抽獎

> 給現場店長／櫃台人員看的「怎麼操作」手冊。看不懂技術沒關係，照步驟做就好。
> 系統設計與驗收細節另見 `docs/15_wheel_campaign_acceptance_report.md`。

---

## 0. 一分鐘看懂這套在幹嘛

1. 門口貼一張 **QR Code**。
2. 客人**掃碼 → 玩輪盤抽獎**，抽獎當下就**自動變成會員**（不用填表）。
3. 抽中的獎變成一張**電子券**，存在客人手機的「我的獎品」。
4. 客人**來店吃飯時**，把券碼給**櫃台**，你在後台**核銷**，這餐就用券。

你（店長）平常只會用到兩個畫面：**門口 QR**（印一次貼著）和 **店長後台**（每天看成效＋櫃台核銷）。

---

## 1. 開店前一次性設定（交給工程或照做一次）

### 1-1. 設兩個密碼（很重要，沒設＝任何人都能進後台）

在伺服器的環境設定（`.env` 或部署平台的環境變數）填這兩行：

```bash
RESTO_ADMIN_PASSCODE=<你要發給店長的後台通行碼>      # 例如自己取一組好記的
RESTO_SESSION_SECRET=<一長串亂碼>                     # 用指令產生，見下
```

產生那串亂碼的指令：
```bash
openssl rand -hex 32
```

> ⚠️ 系統有預設值（`changeme-admin`），**上線前一定要換掉**，否則別人猜得到。

### 1-2. 啟動系統 + 建立活動

```bash
make db-migrate      # 建好資料表（只需第一次）
make wheel-demo      # 建立一個「開幕輪盤」活動，會印出網址
make api             # 啟動系統
```

### 1-3. 印出門口 QR

打開這個網址（把 `<id>` 換成上一步印出的活動編號），會看到一張可列印的 A4 海報：
```
http://<你的網址>/campaigns/<id>/poster
```
印出來貼在門口／櫃台／桌上立牌即可。

## 2. 每天的營運動作

### 2-1. 進後台

電腦或平板打開：
```
http://<你的網址>/demo/admin.html
```
第一次會跳出**登入框** → 輸入你在 1-1 設的「後台通行碼」→ 進入。
（登入後 12 小時內免再登入；右上角可「登出」。）

### 2-2. 看今天活動成效

左邊點選活動 → 右邊「📊 活動成效」會即時顯示：

| 看到的數字 | 意思 |
|---|---|
| 抽獎次數 / 參與人數 | 今天有多少人玩、多少新會員 |
| 中獎率 | 有抽中獎的比例 |
| 核銷率 | 抽中的券，實際來店使用的比例（**回流指標**） |
| 已核銷價值 / 未核銷負債 | 已經送出去的成本 vs 還沒被用掉的潛在成本 |

按「↻ 重新整理」更新數字。

---

## 3. 櫃台核銷（客人來店用券）⭐ 最常用

1. 後台選到活動 → 找到「🧾 櫃台核銷」區。
2. 請客人出示「我的獎品」裡的**券碼**（8 碼，例如 `9TC36U46`），輸入或掃描。
3. 按「查詢」→ 確認獎品名稱正確。
4. 按「確認核銷」→ 顯示成功，這張券就用掉了。

**規則提醒**：
- 同一位會員、同一個活動、**同一天只能核銷一張**（系統會自動擋）。
- 券**過期**或**已用過**會核銷失敗，畫面會提示原因。
- 客人手機端**不能自己核銷**，一定要走櫃台 → 防止有人在家亂按。

---

## 4. 調整中獎機率（大獎中太兇／太少時）

後台活動詳情 → 「🎯 輪盤獎項」表格可**直接改**：

| 欄位 | 調這個會怎樣 |
|---|---|
| 權重（weight） | 數字越大越容易中。大獎中太多 → 調小 |
| 配額（quota） | 這個獎總共最多送幾份；送完自動不再中 |
| 價值（value） | 只影響成效報表的金額估算，不影響中獎 |

改完按 **💾 存檔**，**活動進行中即時生效**。也可把某個獎「停用」暫時不出。

> 💡 開幕首日人潮多怕大獎太快被抽光 → 把大獎權重調小或設低配額。

---

## 5. 對帳（給會計）

後台「📊 活動成效」區按 **⬇ 匯出券 CSV** → 下載一份試算表（Excel 直接開、中文正常），裡面有每張券的：券碼、狀態、獎品、價值、會員、效期、核銷日期。拿這份跟現場紀錄勾稽即可。

---

## 6. 活動上下線時間

建立活動或在詳情的「⏰ 活動排程」可設**開始 / 結束時間（台灣時間）**：
- 想「**開幕日才開跑**」→ 把開始時間設開幕日。
- 活動時間還沒到或已結束，客人抽獎會被擋下並提示。

要手動上下線：用詳情上方的「上線 / 結束 / 轉草稿」按鈕。

---

## 7. 常見問題

| 狀況 | 怎麼辦 |
|---|---|
| 客人說抽不了，顯示「今天已抽過」 | 正常，每人每天限一抽，請明天再來 |
| 客人說抽不了，顯示「活動尚未開始 / 已結束」 | 檢查「⏰ 活動排程」時間設定 |
| 核銷失敗「券已過期」 | 券超過效期了，無法使用 |
| 核銷失敗「今天已核銷過」 | 該客人今天已用過一張，請明天再來 |
| 進不了後台 | 通行碼輸錯，或 session 過期重新登入；確認 1-1 密碼 |
| 大獎一直沒人中 | 正常（機率低）；想多送就調高權重，見 §4 |
| 大獎太快被抽光 | 調低權重或設配額，見 §4 |

## 8. 一句話速查

| 我要做 | 去哪 |
|---|---|
| 貼門口 QR | `/campaigns/<id>/poster` 印出來 |
| 看今天成效 | 後台 → 活動 → 📊 活動成效 |
| 幫客人核銷 | 後台 → 活動 → 🧾 櫃台核銷 → 輸券碼 |
| 調中獎率 | 後台 → 活動 → 🎯 輪盤獎項 → 改權重 → 💾 |
| 給會計對帳 | 後台 → ⬇ 匯出券 CSV |
| 改活動時間 | 後台 → 活動 → ⏰ 活動排程 |

有任何系統問題，附上畫面截圖與活動編號，找工程協助。
