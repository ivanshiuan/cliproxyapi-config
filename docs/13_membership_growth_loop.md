# 13. 會員成長飛輪 — 完整行銷策略與行程閉環

> 把「開幕輪盤抽獎」從一次性活動，升級成**自我循環的會員成長引擎**。
> 本文是策略 SSOT；程式碼落地狀態見文末「實作狀態」。

---

## 0. 一句話策略

> **獲客只是入口，真正的資產是「會員 + LINE 觸達 + 自動把人拉回店裡的引擎」。**
> 一次活動打平就好，靠閉環讓**之後每一檔的獲客成本趨近於零**。

---

## 1. 行程閉環（Customer Journey Loop）

```
   ┌─────────────────────────────────────────────────────────────┐
   │                                                             │
   ▼                                                             │
[獲客 Acquire]  輪盤 QR（門口/桌貼/外帶袋）→ 抽獎=加入會員=加 LINE     │
   │                                                             │
   ▼                                                             │
[啟動 Activate] 首抽歡迎禮 100 點 + 新客券（隔日生效、限 7 天、需到店）  │
   │                                                             │
   ▼                                                             │
[回訪 Retain]   結帳自動發點（tier 倍率）+ LINE 收據 + 升等進度條        │
   │                                                             │
   ▼                                                             │
[升級 Tier-up]  滾動 6 個月消費自動升降級 → 升等道賀 + 永久點數加倍      │
   │                                                             │
   ▼                                                             │
[裂變 Refer]    專屬邀請碼 → 朋友註冊得禮 → 朋友到店消費 → 我繁點數 ──────┘  (飛輪加速)
   │
   ▼
[喚回 Win-back] 沉睡/生日自動 LINE 推播 + 召回點數（只能到店折抵）──→ 回到 Retain
```

**閉環的本質**：每個客人都可能變成下一個獲客來源（裂變），而每個沉睡客都會被自動拉回（喚回）。Circle 一旦轉起來，成長是複利的。

---

## 2. 五大閉環引擎

每個引擎 = **觸發 → 動作 → 渠道 → 衡量**。

| 引擎 | 觸發 | 自動動作 | 渠道 | 衡量 |
|---|---|---|---|---|
| 1 獲客 | 掃 QR | 抽獎＝建會員＋綁 LINE | 現場/LINE | 掃碼→抽獎轉換率 |
| 2 啟動 | 首抽/首註冊 | 歡迎禮 100 點 + 新客券 | LINE | 7 日內首到店率 |
| 3 回訪/升級 | 結帳；每日 job 重算 tier | 發點（倍率）＋升等道賀＋進度條 | LINE | 回訪頻率、tier 遷移 |
| 4 裂變 | 分享邀請碼 | 雙邊獎勵、推薦分潤點數 | LINE | K 因子、推薦獲客數 |
| 5 喚回 | 每日 job 掃 last_visit / 生日 | 召回點數 + 生日禮 + 招待品項 | LINE | 沉睡喚回率 |

## 3. 「不跟人家一樣」的三個頂級黏著機制

一般店只會做 1% 回饋。要輾壓同業，用這三招把「偶爾來」變「戒不掉」：

### 3.1 推薦分潤點數（Referral Override）— 裂變核武
- 你推薦的朋友用你的 **QR/邀請碼**註冊 → 朋友立刻得「新客禮 + 抽獎券」
- 朋友**首次到店消費** → 你（推薦人）得大紅包點數（例：朋友消費額 5% 或固定 200 點）
- 進階：朋友後續 90 天內消費，你持續抽小比例分潤
- **效果**：把每個滿意的客人變成你的業務員，一次推薦、持續回血 → 自發瘋傳。這就是「好吃→分享→朋友來也有點數→朋友下次也來」的 circle。

### 3.2 連續回訪 Streak — 習慣養成
- 連續週/月有來，點數倍率**階梯式加速**（1x → 1.2x → 1.5x …），中斷歸零
- 借用健身/語言 App 的留存神器：**怕斷掉**比折扣更能驅動主動回訪

### 3.3 升等進度條 — 永久權益鎖客
- 「再消費 X 元升白金，解鎖永久點數加倍」
- 進度條效應 > 折價券轟炸；升等是**永久**權益 → 心理鎖死，不想掉等

## 4. 點數與分級經濟學（已採用的決策）

| 項目 | 決策值 | 理由 |
|---|---|---|
| 基礎回饋 | 消費 100 元 = 1 點，1 點 = 1 元（約 1%） | 毛利撐得住、客人有感的地基 |
| **分級基準** | **滾動 6 個月**累積消費（GROSS，折扣不扣 tier 進度） | 窗口縮短 → 逼「半年內回來吃一次」，沒回來自動降級 |
| 分級門檻 | 銀 1,500 / 金 4,000 / 白金 10,000 | 對應 6 個月內不同消費力 |
| 分級權益 | 銀 1.0x、金 2.0x、白金 3.0x 點數 | 越高 tier 越花越划算 → 鎖定（沿用 orders 既有倍率） |
| 歡迎禮 | 100 點 | 降低首購門檻 |
| 生日禮 | 200 點 + 招待品項 | 高轉換、高情感 |
| 沉睡召回 | 150 點（只能到店折抵） | 給回店的理由，不是現金折讓 |
| 點數效期 | 12 個月 | 控負債、製造使用急迫 |

> 以上皆為 `membership_service` / `orders_service` 內的常數，標註可調，未來移入 `tenant_settings` 供各品牌覆寫。

## 5. 「真實讓客人走進店裡兌換」的設計

線上熱鬧 ≠ 到店。把券核銷率從 <10% 拉到 25%+ 的五個手法：

1. **隔日生效**（`voucher_start_offset_days=1`）→ 強制第二次到店動機
2. **短效期 7–14 天** → 急迫感（太長＝永遠不來）
3. **送品項不送現金** → 招牌飲料/甜點免費，逼點主餐，吸真客非羊毛客
4. **到期前 LINE 提醒**（生命週期 job 自動發）→ 把「忘記用」救回
5. **核銷當下 upsell + 再抽一次** → 一次到店榨出「連帶消費 + 下次再來的鉤子」

連帶率關鍵：免單**四人/雙人**套餐 ＞ 免單一人餐 → 帶同伴來，同伴的飲料/加點才是真正賺錢的部分。

## 6. KPI 儀表板（盯這些，不是盯抽獎次數）

| 指標 | 健康區間 | 意義 |
|---|---|---|
| 掃碼→抽獎轉換率 | — | 入口吸引力 |
| 券到店核銷率 | ≥ 20–30% | 線上→線下轉換（最關鍵） |
| 核銷連帶客單價 | — | 核銷者免費品以外實付 |
| 30 日回訪率 | — | 會員資產是否活著 |
| tier 分布與遷移 | 上升 | 升級引擎是否有效 |
| 沉睡喚回成功率 | — | 喚回引擎 ROI |
| K 因子（推薦帶新客數） | > 0.3 起 | 裂變飛輪是否轉動 |
| 單客取得成本 | < FB 廣告獲客 | 整體效率 |
