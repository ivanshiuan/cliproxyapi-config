# Aibou Crew（艾柏雲端）— 台灣排班制產業的「雲端營運長×人資長」HR SaaS 競品蒸餾

## 一句話重點
Aibou Crew 是**只做人力軸**（排班/打卡/薪資/勞基法防呆 + 人力成本預測）的台灣 SaaS，號稱服務近千家門市；它不碰訂單、庫存、COGS、會員 — 我們的全域系統在廣度上直接超車，但它的「勞基法防呆 + 30 秒結薪 + 一小時上線」是值得偷學的深度。

## 核心重點（功能蒸餾）

- **排班**：一鍵排班、支援變形工時等各種班表；臨時請假可在 App 即時改班、電腦後台與手機即時同步。
- **打卡**：QR code 到店打卡 — 人到店才能打，防「還沒到就打卡」。
- **薪資**：「30 秒算完合法薪資」— 自動算加班費、特休補休；員工在 App 看薪資單。
- **勞基法防呆**：排班時內建法規提醒（工時上限、變形工時規則），主打「預防勞資糾紛」。
- **AI/預測**：排班當下即時顯示**人力成本佔營業額比**與成本預測；老闆設門市成本 KPI，主管照著排；宣稱有銷售預測（sales forecast）與最佳班表建議（「AI 店長」）。
- **上手速度**：「一小時上線、一天上手」— 從門市現場視角設計，導入摩擦極低。

## 可用在帝國哪個環節（So what）

**1. 定位結論：它是單軸、我們是全域 — 不是同一場仗，但它佔住了灘頭。**
Aibou Crew 只解「人」這一軸。我們的 RestSwarm 有 25 表：訂單、庫存/BOM、COGS 變異、集點、LINE、audit、mv_daily_pnl 損益 — 加上 clock_router 也覆蓋了它的打卡領域。差異化敘事應該是：「**他們告訴你人力成本佔營收幾 %；我們告訴你今天這家店到底賺不賺錢、為什麼**」（人力+食材+折扣+廢棄全兜進同一張損益）。

**2. 要偷學的三件事（他們做得好的深度）：**
- **勞基法防呆做成即時 guardrail**（排班當下擋，不是月底報表才發現）→ 對應我們 `specs/labor_hours_classifier.md`，應把「違規預警」升級為排班/打卡寫入時的 DomainError 級檢查。
- **「30 秒結薪」的可驗證數字型賣點** → 我們的賣點也要量化（例：「每天打烊 60 秒看懂今日真損益」）。
- **導入摩擦低到誇張**（1 小時上線、60 天免費、月租不綁約、政府雲市集補助）→ 我們 pilot 客戶的 onboarding 與計價可直接抄這個結構。

**3. 定價錨點**：NT$168/人/月 = 市場已接受的人力軸價格。我們是全域系統，可用「人力軸同價、全域功能是倍數價值」定價，或按門市/月計費避開按人頭比價。

**4. 他們的空白 = 我們的主打**：無 POS/訂單、無庫存/BOM/COGS、無會員/LINE 集點、無發票/對帳、無真損益視圖。行銷素材可直接列這張對照表。
