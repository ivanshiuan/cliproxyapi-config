# 好點 POS — 台灣餐飲一站式 POS 競品蒸餾（收錢的機器，沒有損益的腦）

## 一句話重點
好點 POS 是「現場點餐→收銀→出單→線上單→報表」的完整操作外殼，但資料只到營收層 — 沒有庫存/BOM/COGS/損益；我們反過來：損益的腦很強、操作外殼缺一角，本次已把菜單後台、桌位、客製群組、訂單生命週期（加點/退款/未結單）、報表 API 全部補進 RestSwarm（見 `docs/13_haodian_pos_comparison.md`）。

## 核心重點（3–5 條）
- 功能面最完整的台灣小店 POS 樣板：內用外帶、桌號、客製群組（單/複選/必選）、先送單後結、加點/退款/合併/補印、QR+LINE 點餐、外送串接、多元支付、電子發票、標籤機。
- 商業模式靠「依申購方案為準」拆售：QR/LINE、外送、發票都是加購 — 功能表漂亮但全配不便宜。
- 報表只有營收視角（日/月/商品/時段/對帳），**無成本無毛利** — 這是我們最大的打點。
- 員工管理極淺（打卡+出勤報表而已），會員一句帶過 — 對照 Aibou Crew 卡：兩家各佔一軸，我們是唯一全域。
- 「日常營運流程」章節（開店前/營業中/閉店前）寫得好 — onboarding 敘事值得抄。

## 可用在帝國哪個環節（So what）
- **產品**：他們的功能表就是「店家期待的最低標」— 已據此補齊 G1–G8（菜單後台/客製/桌位/訂單來源/加點/退款/查詢/報表），每張報表多「成本+毛利」欄當差異化。
- **行銷**：一句話對打 —「好點告訴你今天收了多少錢；我們告訴你今天賺了多少錢」。
- **定價**：他們拆售加購的痛（QR/發票/外送都要加錢）→ 我們可打「全域一價」。
