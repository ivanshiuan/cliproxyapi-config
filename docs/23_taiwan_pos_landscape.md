## 3. 我們已領先的驗證（多家對照後仍成立）

- **內場完整度**＝iCHEF 級（桌位/併桌/拆單/招待/退菜覆核/交班關帳/自動折扣），而肚肚/快一點/微碧的內用縱深都是空或淺。
- **BOM 庫存扣料+成本對帳**：肚肚被第三方點名做不到、微碧只有成品庫存、快一點只有可售量——我們的配方扣料+COGS 異常偵測在同價位帶罕見。
- **append-only 稽核帳本**＋主管覆核記錄授權者：全場沒有一家公開資料做到這個等級。
- **Web-based 任意裝置**：全場除 SHOPLINE 外都綁 iPad；我們任何平板/手機/電腦瀏覽器即 POS。
- **WebSocket 秒級同步**（POS/KDS/顧客/看板同一條流）：其他家未見公開的同級架構。
- **成長飛輪**（輪盤/裂變/UGC/儲值加贈）：只有 Ocard 在會員行銷上更深（見 G7）。

## 4. P9 建造順序建議（超越全場，可自主建優先）

1. **Kiosk 自助點餐模式（G1）＋ 遠端線上候位頁（G6）** — Web 架構天生優勢，成本最低、缺工痛點最大
2. **放題/吃到飽模式（G2）** — 台灣大業態，Eats365/WeiBy 拿它收高月費
3. **Tier Pricing 差別定價（G3）＋ 時段限流（G9）** — 定價與產能的兩把刀
4. **訂位訂金規則引擎（G4 規則層）＋ 每桌訂位規則（G5）** — 對標 inline，扣款等金流
5. **自動化行銷劇本（G7）＋ 會員升等（G13）** — 對標 Ocard，我們基礎最接近
6. **電子禮券（G10）＋ 揪團合購（G8）** — 現金流與客單價
7. **多店菜單同步（G11）＋ 員工業績認列（G12）＋ Expo 屏（G15）＋ 情境通知（G14）** — 收尾件
8. （等憑證後）LINE OA 點餐、車隊媒合、訂金扣款

**🔴 等 Ivan 的新增項**：LINE 官方帳號（LINE 點餐/通知型訊息需要）、車隊 API 帳號（Uber Direct/pandago）。
