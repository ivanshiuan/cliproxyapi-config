# TIGER LINE PRIME — 個人作戰手冊

> **給誰看**：Ivan
> **看什麼時機**：每天賽前 90 分鐘、每次要下注前、賽後 6 小時內、每週日晚上
> **核心思想**：不追求每場命中，追求每場「有紀律地做對的事」

---

## 一句話：系統對你的好處

**沒有系統時：**
你憑「感覺這場像小分盤」、「這隊最近狀態好」、「盤口深了應該有貓膩」下注。當週準了，本金上升，你會**下更重**；當週輸了，你會**追回**。10 場後，你不知道自己是準還是運氣，也不知道問題出在場型判斷、下注時機、還是資金配置。

**有系統時：**
每場都被逼著寫出：**場型分類 + 信心分數 + 主單選擇 + 資金比例 + 賽後結果**。3 個月後你有 50-100 筆結構化資料，可以回答：
- 我在「兩球勝落點盤」是不是真的準？
- 我在「壓力小分盤」是不是常常追高？
- A+ 級主單的長期 ROI 是正的還是負的？
- 我下的盤是不是打贏封盤（CLV beat rate）？

**這就是最大的好處**：從「感覺型玩家」變成「有數據可調整的玩家」。系統不保證你贏，系統保證你**知道自己為什麼贏或輸**。

---

## 紀律五條 — 破一條就當天全部歸零

1. **系統說 SKIP 就 SKIP**。不管你多喜歡那場、不管你朋友怎麼說、不管盤口看起來多誘人。SKIP 就是不下。
2. **A+ 也不超過本金 25%**。單場最大曝險是硬性上限。過線就是自欺。
3. **一天總曝險 ≤ 45%**。連 4 場 A 級一起下也不行。
4. **輸掉 35% 當日本金就停手**。當日虧 35% 直接關電腦、明天再看。追損就是死路。
5. **感覺跟系統衝突時，聽系統**。感覺說「這場一定小球」但系統分類是 `goal_market`（進球盤）、Precision Score 60 → 就是不下小球。感覺可能對，但你沒有數據證明感覺對，系統至少有規則對錯可查。

## 每日 SOP — 從賽前 24 小時到賽後 6 小時

### T-24h 賽前一天（每天早上 10 分鐘）

- [ ] 打開今日的比賽清單
- [ ] 每場建立 `match_id`（例：`2026-wc-belgium-newzealand`）
- [ ] 建立 `matches/<match_id>.tiger.json` 或直接抓範例改
- [ ] 手動填 `team_need`（must_win / draw_ok / rotation / neutral）
- [ ] 手動填 `group_context.final_round`、`same_time_kickoff`
- [ ] 加 `risk_flags`：`favorite_already_qualified`、`key_player_out`、`weather_risk` 等

**紀律點：** 資料填不完就不下。系統會在 `data_quality` 攔截，你也要在腦袋裡攔截。

### T-3h 賽前三小時（每場 5 分鐘）

- [ ] 把當時看到的盤口記進去：`tiger snapshot add <path>`
- [ ] 至少 2-3 個平台的盤口（Pinnacle、Bet365、你實際下注的平台）
- [ ] 這樣後面才能跑 `movement` 跟 `consensus`

### T-90m 賽前一小時半（決策時間）

一場一次跑這 5 個指令：

```
tiger analyze matches/<match_id>.tiger.json      # 場型 + 主單建議
tiger movement analyze <match_id> --market AH_full  # 盤口動能
tiger consensus show <match_id> --market AH_full --user-book <你的平台>  # 你平台好不好
tiger precision score <match_id> --user-book <你的平台>  # 0-100 分
tiger report daily <match_id> --tier vip         # 一頁式報告
```

看報告最後一行是什麼等級：

- **A+（≥90 分）**：主攻，建議本金 20-25%，硬性上限 25%
- **A（80-89）**：可下，建議 12-18%
- **B（70-79）**：小注 7-12%，或跳過等走地
- **C（60-69）**：小注 3-6%，或跳過
- **D（<60）**：**跳過**

**紀律點：** 分數低於 70 一律**跳過**，不管你多想下。90 天後回頭看，你會謝謝自己。

### T-15m 賽前 15 分鐘（先發公佈後最後檢查）

- [ ] 再收一次盤口 snapshot
- [ ] 跑 `tiger movement analyze` 看有沒有 steam move / RLM
- [ ] 如果讓球盤在最後 15 分鐘反向大跳（`favorite_weakening` + velocity=fast）→ **降碼一級或跳過**
- [ ] 如果核心球員不先發 → **降碼一級或跳過**

### 賽後 6 小時內（不要拖過夜）

```
tiger review <match_id> <H>-<A>              # 記錄結果 + 拿到 suggestions
tiger report review <match_id> <H>-<A>       # 產出人類版復盤報告
tiger clv summary                            # 看 CLV beat rate
```

只做兩件事：**記錄** + **看 suggestions**。**不要**當下改 YAML 規則。今天輸了改規則、明天贏了又改回來 = 沒有規則。

## 週日 30 分鐘週回顧（紀律的關鍵）

```
tiger stats --since <上週日>                 # 每個場型的命中率
tiger report calibration --since <上週日>    # Brier / log-loss / per-bucket 命中
tiger clv summary --since <上週日>           # 我打贏封盤多少場
```

問自己 5 個問題：

1. **哪個場型 main_win_rate < 50%？** → 那個場型 rules 太寬，下週調緊。
2. **A+ 的實際命中是不是接近 90%？** → 如果只有 70%，代表系統對「A+」定義過寬。
3. **CLV beat rate 是否 ≥ 55%？** → 如果只有 40%，代表我下的盤比封盤差，長期必虧。
4. **這週有沒有破紀律五條？** → 有 → 記下當時為什麼破 → 加一條個人 rule。
5. **這週淨盈虧？** → 記帳。

**紀律點：** 週回顧是**看數據不看情緒**。不要因為週輸就整個系統打掉重練。

## 90 天實戰整合計畫

**Phase 1：只跑不下（第 1-30 天）**

- 每場都跑系統、記錄建議、但**只下你原本會下的**
- 賽後兩邊都記錄：系統說什麼、你實際下什麼、結果
- 30 天後有 30-50 場資料，開始看：**如果我照系統下、我這 30 天是賺還是賠？**

**這是最重要的 phase。** 不做這步直接押錢，跟盲目換工具一樣蠢。

**Phase 2：小額同步（第 31-60 天）**

- 系統說 A+，你下**原本的 30%** 額度
- 系統說 SKIP，你**真的 SKIP**（練紀律）
- 系統跟你感覺衝突時、**聽系統一半**（半倉）
- 每週日回顧「感覺 vs 系統」的差距

**Phase 3：標準額度（第 61-90 天）**

- 系統說 A+ 就下 20-25%
- 系統說 SKIP 一定不下
- 感覺跟系統衝突時、**聽系統**
- 感覺很強烈想推翻系統？→ 把感覺寫下來當「假設」、等 10 場之後看假設對不對

## 系統跟你既有下注習慣的整合

**你原本可能：**
- 靠 「看熱門球隊 + 感覺盤口」下 3-5 場
- 波膽亂灑
- 連續輸就追損

**整合後：**
- **每天 3-5 場依然可以**，但每場都要過系統的紀律五條
- 波膽只買**比分走廊內**的，且總曝險 ≤ 12%
- 追損被紀律 4 擋住（35% 停損）

**系統不是取代你，是**用工程化紀律鎖死你原本會犯的錯**。

## 常見陷阱與破解

| 陷阱 | 破解 |
|---|---|
| **今天不 SKIP、感覺會過** | 打開手機看紀律五條第 1 條 |
| **A+ 超過 25% 一次過** | 錢包直接把 25% 上限存另一戶 |
| **輸掉 35% 想追回** | 停損卡放電腦旁邊、輸到就關機 |
| **感覺跟系統衝突就聽感覺** | 感覺贏就贏一場、輸就輸 3 場、聽系統長期正 |
| **週輸就想改 YAML** | 週回顧是看數據不看情緒、規則改動至少累積 20 場再說 |
| **連續 5 場 SKIP 手癢** | SKIP 也是決策、5 場全 SKIP 就是這週的策略 |
| **賽後不記錄** | tiger review 是最重要的環節、輸的場更要記 |
| **完全信任系統不動腦** | 系統是規則、你才是判斷、看到不合理的建議先問為什麼 |

## KPI — 每週日看這 4 個

1. **當週 ROI**（單週回報率）
   - 目標：> 0
   - 警戒：連續 3 週 < 0 → 停手、重看規則

2. **A+ 命中率**
   - 目標：≥ 80%
   - 警戒：< 65% → 系統對「A+」定義過寬、下週調緊

3. **CLV beat rate**
   - 目標：≥ 55%
   - 警戒：< 45% → 我下的盤比封盤還差、長期必虧、需要改下注時機

4. **紀律破戒次數**
   - 目標：0
   - 警戒：> 0 → 這週回顧重點是「為什麼破戒」不是「賺多少」

## 三個月後的自己會知道什麼

**現在的你不知道：**
- 「兩球勝落點盤」你到底是準還是靠運氣
- 你在哪個時段下注最容易輸
- 你信心 90 分的盤實際命中率
- 你跟市場封盤的差距
- 你這個月是憑本事賺還是憑運氣

**三個月後的你會知道：**
- 每個場型的 hit rate、ROI、Brier score
- 你在賽前 3h vs 15m 下的盤 CLV 差多少
- A+ 的實際命中率、跟系統分數是否吻合
- 你這個月 X% 是本事、Y% 是運氣
- 下個月該加什麼場型、放棄什麼場型

1. `git pull` 或打開 PR #18 merge 到 main
