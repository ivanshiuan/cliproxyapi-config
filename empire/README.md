## 檔案命名規則

```
日期_類別_文件名稱_版本_狀態
範例：20260705_募資_投資人說明書_V1.0_正式對外
```

狀態只有四種：`正式對外` / `正式`（內部）/ `內部草稿` / `作廢`。
**一份文件只能有一個正式版**；舊版移到「作廢」並在文件版本總控表登記。

## 每日作戰節奏

- **09:00–09:30 生死線**：現金流戰情表 → 今日 3 個資金決策
- **12:00–13:00 工程線**：廠商進度 → 報價付款 → 更新工程預算總表
- **21:00–22:00 文件線**：更新版本總控表 → 標紅燈 → 明日決策清單
