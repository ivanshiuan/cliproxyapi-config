| 狀態 | 條件 | 行動 |

| 🟢 綠燈 | 30 日內現金足夠覆蓋應付款 | 正常節奏 |
| 🟡 黃燈 | 14 日內現金不足，但有確定入金可補 | 盯入金日期，暫停一切非必要支出 |
| 🔴 紅燈 | 7 日內現金不足，且無確定入金 | 今日 3 決策全部圍繞找錢／延付 |
| ⚫ 黑燈 | 租金、工程款、貸款其中一項已逾期且無解法 | 停止所有非生存活動，立即啟動危機處理 |

## 使用規則

1. 每日 09:00 填寫，09:30 前排出今日 3 件資金決策 — **每日最多 3 件核心決策**。
2. 「承諾未入金」不算現金 — 燈號判定只看「今日可動用現金 + 已確認入金」。
3. 燈號變 🔴 或 ⚫ 當天，同步在文件版本總控表標記紅燈風險。
4. 任何付款前先對照工程預算總表的付款節點控管，**防止太早付太多**。
