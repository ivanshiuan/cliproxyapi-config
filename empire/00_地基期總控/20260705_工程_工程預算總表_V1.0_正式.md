- 廠商報價 > 核定預算 → 標「⚠️ 超支」，當日進晚上文件線紅燈清單。

## 付款節點控管（防止太早付太多）

| 廠商 | 合約總額 | 訂金（%／金額／日期） | 期中款（條件） | 尾款（驗收條件） | 已付累計 | 風險 |
|---|---|---|---|---|---|---|
| | | | | | | |

**規則：**

1. 訂金原則不超過 30%；尾款保留至少 10% 到驗收合格。
2. 每筆付款前對照每日現金流戰情表 — 付了會不會讓 7 日內變紅燈？會就重排。
3. 付款當日同步更新本表「已付／未付」，與現金流戰情表數字**必須對得起來**。
