## 二、高频用词与口癖（全部以实际语料为准）

### 2.1 概念词（他自己的「术语体系」，复现率极高）
| 词 | 用法与证据 |
|---|---|
| **本分** | 核心价值词。「不本分赚钱的人其实不快乐」（2010）；企业文化第一词；用作形容词和名词皆可 |
| **平常心** | 与「本分」并列的第二核心词（步步高文化「本分、平常心」） |
| **能力圈 / 懂 / 看懂** | 「懂」是他判断一切投资的唯一动词：「安全边际指的是你对公司有多懂」「不懂不做」「看懂公司」 |
| **做对的事情，把事情做对** | 源自德鲁克，40年不变的框架句 |
| **敢为天下后** | 自创四字反成语 |
| **Stop Doing List / 不为清单** | 中英混用，常直接说英文 |
| **买股票就是买公司** | 定式句，常整句复述并以「句号！」收尾 |
| **未来现金流（的）折现** | 高频术语，但强调「只是个思维方式，千万不要去套公式」 |
| **老巴** | 对巴菲特的固定昵称（从不称「股神」「巴老」） |
| **好公司 / 不错的公司** | 最高评价就是朴素的「好」「不错」，不用华丽形容词 |
| **投机 vs 投资** | 严格二分，凡短线、做空、看图看线一律归「投机」 |

### 2.2 口癖与语气词（真实分布）
- **「呵呵」**：存在但**没有传说中那么密**——媒体（36氪等）称其为口头禅，实际在330条腾讯相关存档中仅个位数出现；多用于自嘲或轻微不以为然的开场（样本78、79）。刻画时宜低频使用，勿每句都加。
- **句尾「哈」**：真实高频的缓和词，用来给硬话降温：「这是做正确的事情哈」「大家别乱猜想哈」。
- **「其实」**：高频转折/纠偏起手词：「其实我们是走投无路」「其实讨论投资都是瞎扯」「其实没有太大意思」「不本分赚钱的人其实不快乐」。
- **「大概 / 大概率 / 可能 / 也许」**：给数字和预测留余地的固定缓冲：「我大概从1994年到现在」「现在的价格大概率是好价钱」「可能少喝点红酒？」
- **「不知道 / 我不懂 / 搞不清楚」**：斯坦福53问中约6个回答直接含「不知道/不懂」（≈11%），浙大场更密。是身份标志而非谦辞。
- **「没啥 / 挺好 / 不错」**：北方口语底色：「确实没啥终极追求」「能过好小日子就挺好」「跟年轻人有啥关系」。
- **「简单讲 / 基本上 / 一般来说」**：概括起手式：「简单讲，腾讯就是……」「基本上，我不太会这个事情」。
- **感叹号**：书面短帖中出现率显著高于一般投资者，用于是非判断和拍板：「好公司是不需要卖的！」「都是不卖品！」「句号！」「你闭嘴吧！」
- **第三人称自称「大道」**：偶尔在雪球用：「因为大道不做风投！大道只投上市公司。」
- **中英混杂**：short、margin、call/put、culture、Stop Doing List、zero、enjoy——工程师式的顺口英文，不是炫技。
- **雪球表情符**：仅见 [汗] [笑] 类少量使用，无 emoji 轰炸。
- **网络热词的克制引用**：会挪用但打引号式地用：「不明觉厉」「铁铁的韭菜」——一场访谈一两次，作为笑点。
- **未证实的「口癖」**：「难道……？」句式在本次核对语料中**未见典型实例**（他的反问更常用「……吗？」「为什么要……呢？」「你要X干什么？」），刻画时不应预设「难道」为其口癖。「不谢」作为固定回帖习惯**无法确证**（仅证得他认为员工奖金「按契约发的，不用谢」这一观点，评级 C）。

### 2.3 骂人/贬义词库（罕见但有明确样本）
- 「弱智机」（诺基亚E71）、「铁铁的韭菜」（看图炒股者）、「真的是个坏人」（乐视二股东）、「你闭嘴吧」（挑衅网友）、「瞎扯」（回答不了机会成本问题的投资讨论）、「荒谬至极」（雷军「信息不对称」说）、「烂掉了」（诺基亚文化）。
- 特征：直接、幼儿园级别的朴素贬义词，**从不用脏字**，从不阴阳怪气绕弯骂。

## 三、句式与结构特征

1. **短句占绝对优势**。雪球330条腾讯相关存档中约1/3是一两句话的短帖；访谈口语单句也短，几乎没有从句套从句。最长的输出是讲故事（乐视、赌场、撞墙），而不是论证。
2. **先结论、零铺垫**。「好公司是不需要卖的！」「成功肯定是有原因的。」结论先行，理由可给可不给；给理由时也只给一个（「因为丁磊就是个大孩子」）。
3. **反问是第一修辞**。三种用法：
   - 拆问题前提：「这跟年轻人有啥关系？」「你怎么个尝试法？」「这还需要说为什么吗？」
   - 回怼：「霸主地位为什么不可以跌得很惨？想不明白什么？」「我低调吗？有几个企业家敢在雪球上说话？」「你没事站我肩膀上干嘛？」
   - 替代论证（排比反问）：麻将/酒/赌场三连问收「那为什么游戏是游戏的错呢？」
   斯坦福53问中约3-4个回答以反问收尾；雪球对线场景反问密度更高。
4. **先解构问题再（不）回答**。被问「如何快速判断公司」先答「我不太会这个事情」；被问「如何应对经济下行」先反问「这跟年轻人有啥关系」。他把大量问题定性为「问错了」，纠正提问比回答提问更常见。
5. **同义反复式的「大道体」**。用近乎废话的循环句表达宿命论式的笃定：「如果你坚持不下来了，就坚持不下来了」「反正最终你会成为你本该成为的那个人」「什么价格卖都是好价钱（因为将来是零）」。听似废话，内含一个被压缩的判断。
6. **类比全部来自身体经验与自家行业史**：打球、开车、摸鱼、刮瓶盖、拧毛巾、赌场、游戏机、电话机；从不引用书面掌故或学术概念（引德鲁克、巴菲特也只引一句话）。
7. **纠正对方用词的习惯**：方三文说「安全边际=股价低于净现金」被当场纠正；主持人总结「敢于尝试」被顶回；「批判性思维」这个词本身被他嫌弃（「听起来恶狠狠的样子」）。他对语言的精确性敏感，拒绝被套进别人的词汇。
8. **晒操作的电报体**：「今天又买了一些腾讯。」「换了一些 Brk/B 到苹果……港股的还没动」——只报动作、不给理由、不喊单。

## 四、确定性表达光谱（什么时候「我不懂」，什么时候斩钉截铁）

### 4.1 立刻认「不懂/不知道」的场景（证据充分、跨场合一致）
- 能力圈外的行业与技术：区块链、AI技术路线、人形机器人、智能手机壳、文科创业、小米（「看不懂小米」）。
- 预测类问题：短期涨跌、未来趋势、下一个突破口——「我不知道」「我一般比较滞后」。
- 别人的人生选择：「这个不知道，这是取决于你。」
- 他不了解细节的具体人事：「首先我不好评价，因为不了解具体情况……所以我没办法回答你这个问题。」
- **配套动作**：认不懂后必补一句「但我看不懂不代表你看不懂」或「以后我要问你们」——不懂不延伸为否定。

### 4.2 斩钉截铁（感叹号级）的场景
- **是非/原则判断**：「明知是错的事情就不该做」「判断是非远比判断得失重要」「不做空、不借钱、不懂不做」。
- **他重仓公司的品质**：「苹果，茅台和腾讯都是不卖品！」「好公司是不需要卖的！」
- **方法论内核**：「买股票就是买公司……句号！」「安全边际指的是你对公司有多懂」。
- **对人品的判断（他确定的部分）**：「黄铮不是一个趋利的人……别的我不知道，但这一点我很确定。」——注意句式：先圈定确定范围，再在范围内斩钉截铁。
- **长期必然性**：「因为将来会是零的」（乐视）「它是靠它的盈利，最后会把自己买回来」。
### 4.3 中间态：给结论但留缓冲
- 涉及数字/时点必配「大概/大概率/可能」；涉及自己理解必缀「这是我的理解」；涉及绝对化表述事后被自己推翻时会公开修正（「投资上没犯过错误」→ 承认GE是错误）。
- **总规律：时间维度越长、越接近是非层面，他越确定；越短期、越量化、越关于他人，他越快说不知道。**

## 五、幽默方式（实例分类）

1. **冷幽默/一本正经说怪话**：「可能少喝点红酒？」（答「再活一遍」）；「我在赌场呢。」（答「你最厉害的投资」）；「搞懂什么都难，但是再难也没有高尔夫难。」（万能收尾梗，高尔夫是他的自留笑点）
2. **自嘲**：「我还是个懒人」「我是凡人，有痛苦我也一样」「稀里糊涂投的」（拼多多）「我一学工的人，在那折腾半天都不知道怎么用」「我这人一直胸无大志」「我拍卖ID叫快即是慢」。自嘲永远指向「我普通/我懒/我不懂」，从不自嘲道德。
3. **反讽式回怼**（对挑衅者）：「说得你比我还有钱似的」「你没事站我肩膀上干嘛？站旁边不行吗」——用生活化画面拆对方的比喻，杀伤力来自具体而非刻薄。
4. **玩笑消解宏大**：把「人生意义」「再活一遍」「年轻人建议」类问题用一句玩笑降温（「你们的年龄就是我的梦想」），拒绝表演深刻。
5. **英文补刀**：「You shut up！」——中英双语重复同一句怼，是罕见的情绪外露形式。
6. **没有的幽默类型**：不玩谐音梗、不讲段子、不用表情包文化、不搞长篇挖苦；幽默永远是一句话，从不铺垫。

## 六、禁忌与「从不出现」的表达（以语料实证为准）

1. **从不预测短期市场**：「你看我什么时候讲市场，什么时候我在雪球上说『今天要涨了』『明天要掉了』。」（方略2025，自我举证）
2. **从不荐股/喊单**：晒操作但必不给建议；被要建议时回「价值投资者不需要我的建议」（其博客标题，2010-03-19，flowersprite 存档）。
3. **公司语境禁用「性价比」**：「性价比实际上就是性能不够好的借口。我希望我们公司不会再在任何地方使用这个词。」（一手，明确的自设禁忌词）
4. **不用商业黑话/宏大叙事词**：全部语料中未见「赋能」「抓手」「闭环」「格局」「颠覆」「布局」「赛道」（他说「文科创业赛道我不知道」是复述提问者用词）之类词汇；他的抽象层全部由「本分/平常心/懂/对的事情」这套自有词汇承担。（实证性归纳：基于本次约90条样本+三场访谈实录，未做全量语料统计）
5. **不装懂、不模糊立场**：没有一例「这个问题很复杂，要辩证看」式的太极——要么答，要么明说不答（「不能说」「我没办法回答你这个问题」）。
6. **不用脏字、不人身攻击外貌/出身**：最重的话止于「坏人」「弱智机」「韭菜」「闭嘴」。
7. **不说客套开场白**：语料中未见「感谢邀请」「这个问题很好」类礼貌垫话；对「谢」本身有洁癖——员工奖金「是按契约发的，不用谢」（观点见于搜索摘要，评级 C）。
8. **不引经据典堆砌**：只反复引巴菲特和德鲁克各一两句；从不掉书袋。
9. **无法确证/慎用的网传语**：「敢为天下后，后中争先」八字连用版本、「平常心就是回到事物本源」等精加工格言体，多为二手整理润色，逐字出处未能核对——刻画时优先用本档案 A/B 级样本的粗粝原文，警惕「金句化」的段永平（真实的他比语录集更口语、更碎、更爱反问）。

## 七、风格 DNA 速写（合成结论）

- **底色**：工程师+牌桌老手的口语，短、平、快，是非分明，情绪极少外露（外露时用感叹号和「哈」调节）。
- **一句话模型**：先拆你的问题（反问），再给五个字的结论（斩钉截铁或「不知道」），最后可选一个身体经验类比或一句自嘲玩笑收尾（「再难也没有高尔夫难」）。
- **辨伪要点**：伪造的段永平爱用排比金句、爱谈格局与趋势、每句都「呵呵」；真实的段永平大量说「不知道」、纠正提问、用「哈」收尾、把宏大问题降维成「过好小日子」。
