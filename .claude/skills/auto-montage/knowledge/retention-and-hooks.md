# 留存與鉤子｜Retention / Hooks / 版位 / CTA

> 原創方法論。目的：在生成前**塑形 brief**，不是事後補救。短影音的勝負在「前 2 秒」與「節奏」。

## 1. 前 2 秒鉤子（最重要）
觀眾在 2 秒內決定滑不滑掉。開場必須給「為什麼要看下去」的理由，挑一種：
- **利益型**：「3 步驟，在家複刻這碗牛肉麵。」
- **反差型**：「這家店看起來很普通，但…」
- **衝突型**：「90% 的人煎牛排都做錯這件事。」
- **懸念型**：「先別走，最後一秒有彩蛋。」
- **視覺型**：直接給最誘人的一幕（湯汁、油爆、拉絲）當首幀，**不要黑場開場**。

塑形動作：把鉤子寫進腳本第一句 + 指定首幀鏡頭，不要交給引擎自由發揮。

## 2. 節奏（保持滑不掉）
- 短影音單鏡頭 2–3 秒；資訊密度高，但每句只講一個點。
- 每 5–7 秒給一次「新刺激」（新鏡位/新資訊/音效命中點）。
- 字幕跟著重音節奏出現，關鍵字可放大/變色（但全片風格統一）。

## 3. 結構模板（依片型挑一個）
- **菜色介紹（30s）**：鉤子(2s) → 主體特寫×3(各 3–4s) → 製作/亮點(8s) → 店資訊+CTA(5s)。
- **宣傳片（60s）**：鉤子(2s) → 氛圍鋪陳(10s) → 招牌×3(各 6s) → 故事/理念(15s) → 店資訊+CTA(7s)。
- **紀錄片 montage（90s，真實素材）**：場景設定 → 主題推進(3–4 段) → 情緒高點 → 收束反思。

## 4. 版位安全區（手機 UI 會擋）
- 直式 9:16：上下各留 ~10%、左右各留 ~5% 不放關鍵字幕/資訊。
- 重要主體置於畫面中央 60% 安全框內。
- 字幕底部不要貼齊邊緣，留出平台 UI（帳號名/按鈕）空間。

## 5. CTA（結尾轉化）
- 一支片**只給一個** CTA：到店 / 追蹤 / 點連結 / 私訊優惠，挑最想要的。
- CTA 要同時「講出來（旁白）+ 寫出來（字幕/卡片）」。
- 餐飲到店型：outro 卡片放 店名 + 地址 + 營業時間，並口播一次。

## 6. 雙語策略
- 中文為主、英文為輔（或依目標市場反過來），但**全片統一**。
- 兩種語言各自符合 CPS 與行長上限（見 pitfalls A），不是把中文硬翻塞滿。
- 標題/CTA 的雙語要對等傳達「同一個利益」，不是逐字直譯。
