# 餐飲短影音模板｜Restaurant Vlog Template

> 給餐飲題材的預設骨架。套用後再用 `knowledge/` 微調。預設：直式 9:16、中英雙語、零金鑰可跑。

## 1. 片型快選
| 片型 | 時長 | 目的 | 主 CTA |
|---|---|---|---|
| 菜色介紹 | 20–30s | 單一招牌引流 | 到店點這道 |
| 上新/優惠 | 15–30s | 限時轉化 | 私訊/到店領 |
| 店家宣傳 | 45–60s | 品牌印象 | 追蹤+到店 |
| 紀錄片 montage | 60–90s | 故事/氛圍 | 追蹤 |

## 2. 鏡頭清單（菜色介紹預設）
1. **鉤子首幀**：最誘人一幕（湯汁淋下/拉絲/油爆），2 秒。
2. **主體特寫 ×3**：不同角度/細節，各 3–4 秒，光線偏暖。
3. **製作/亮點**：手法或食材亮點，8 秒。
4. **店資訊 outro**：店名+地址+營業時間卡片 + 口播 CTA，5 秒。

## 3. 聲音設計
- 旁白：Piper TTS（免費）即可；要更自然再考慮付費（先報價）。
- 招牌聲：上菜聲/油爆聲/湯沸聲保留並略提，BGM 壓到 -18~-24 dB。
- BGM：輕快、版權安全來源；比片短時 loop + 交叉淡入。

## 4. 字幕（雙語）
- 中文主、英文輔，全片統一排版。
- 各自 CPS / 行長依 `knowledge/pitfalls.md` A 節；交片前過 `subtitle_align_check.py`。
- 菜名雙語對等（如「紅燒牛肉麵 / Braised Beef Noodle Soup」），不逐字硬翻。

## 5. outro 必填（逐字核對）
- 店名：________
- 地址：________
- 營業時間：________
- 一句 CTA（口播+字卡）：________

## 6. 合規檢查（餐飲）
- [ ] 無誇大/療效宣稱
- [ ] 價格/優惠與店內一致
- [ ] 素材授權 OK（自有或免費開放來源）
- [ ] 店資訊正確
