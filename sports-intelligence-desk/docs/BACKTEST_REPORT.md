# 大規模回測報告（誠實版）

跑法：`node backtest_sim.js 8000`（種子固定、可複現）。
方法：DGP 用 log-linear（與引擎公式異構，非循環）；引擎只看到「真實強度+觀測雜訊」的評級；
市場 = 真實機率+抽水+熱門偏誤+雜訊。對比基準：模型 vs 市場 vs 均勻亂猜。

## 結果摘要（8000 場）

| 指標 | 校準前 | 校準後 (γ=1.25) | 解讀 |
|---|---|---|---|
| Brier 真相(下限) | 0.5329 | 0.5329 | 理論最佳 |
| Brier 模型 | 0.5503 | **0.5464** | 改善 |
| Brier 市場(含抽水) | 0.5356 | 0.5356 | 近神諭對手 |
| Brier 均勻 | 0.6667 | 0.6667 | 亂猜 |
| 資訊量(Skill vs 均勻) | 17.5% | **18.0%** | 有資訊量 |

## 三個誠實結論

### ✅ 1. 模型有真實資訊量
Brier 0.546 << 均勻 0.667（Skill 18%），且距理論下限僅 0.013。模型**不是亂猜**。

### ✅ 2. 校準問題已修復
校準前熱門被嚴重低估（預測 74% 實際 85%）。用 temperature scaling（γ=1.25，
**兩種子樣本內外一致、非過擬合**）修正後，可靠度幾乎完美對齊：

```
區間      預測   實際
70-80%    74.6   76.3
80-90%    84.1   88.5
90-100%   91.7   95.7
```
此校準 (CALIB_GAMMA) 已烤進 `engine.js`，套用於 1X2 的評級/Edge/顯示。

### ⚠️ 3. 打不過「神諭市場」——這是測試設計，不是模型壞掉
模型 Brier 0.546 仍略高於市場 0.536。原因誠實說：**本回測的模擬市場是用真相機率造的**，
近乎神諭，本就極難打敗。同理 Edge 偵測在此設定下表現差（聲稱有 edge 時多半是模型自身殘差）。

**真實世界不同**：真實盤口有結構性低效（散戶情緒、熱門偏誤、資訊延遲），真 Alpha 來自那裡。
這只能靠**實戰賽後回測**證明，無法用模擬代替。

## 待辦（提升真實準度）
1. **實戰回測累積**：賽後填 `SID.results` → `backtest.js` 出 Brier，持續低於真實市場才算有 Alpha。

3. A3 球員校正 xG：減少 λ 估計的觀測雜訊 → 縮小距理論下限差距。

## A5 Ensemble（已完成，回測證實）

洞察：模型與市場誤差**不相關**，加權集成優於任一。
在「真實低效市場」設定（biasNoise=0.07）下，擬合最佳 w_model≈0.4（兩種子一致），

| 估計 | Brier |
|---|---|
| 真相(下限) | 0.5329 |

→ **集成同時優於模型與市場**。UI 單場頁以「集成估計」為最準的機率頭條；
Edge（純模型 vs 市場）保留為高風險投機訊號。
